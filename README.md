# Green Earth



## 📝 Overview
Green Earth is an eco-friendly platform where users can buy trees, track their growth, and view detailed information about each tree. The application promotes environmental sustainability by making tree planting and ownership transparent and interactive. Users can easily explore different tree types, check availability, and make purchases.
